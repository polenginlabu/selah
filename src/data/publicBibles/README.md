# Bundled public-domain Bibles

These translations ship with the app so they read offline with no API request.
Each `<id>/<BOOKID>.json` is one book (USFM book codes from
`supabase/functions/_shared/bible.js`): an array of chapters, each an array of
verse strings, verse number = index + 1. `null` marks a verse the translation
omits from its main text (listed in `KNOWN_OMISSIONS` in the build script).

Generated by `node scripts/bible/build-public-bibles.js` from eBible.org's
verse-per-line downloads. Do not edit the JSON by hand. Licensed translations
(NIV, NLT, MSG, AMP, ESV) are never bundled; they stay on their remote APIs.

Retrieved 2026-10-03. Rights statements below are quoted verbatim from each
translation's eBible.org copyright page on that date.

## WEB — World English Bible (`web`)

- Source: https://ebible.org/Scriptures/eng-web_vpl.zip (eBible.org id `eng-web`)
- Edition: World English Bible Classic, 2020 stable text, source files dated 2 Oct 2026. Protestant canon only; the Apocrypha/Deuterocanon in the download is not bundled.
- Rights (https://ebible.org/eng-web/copyright.htm):

  > The World English Bible is in the Public Domain. That means that it is not copyrighted. However, "World English Bible" is a Trademark of eBible.org.

  > All we ask is that if you CHANGE the actual text of the World English Bible in any way, you not call the result the World English Bible any more.

  The build applies the same clean-up to every translation: whitespace is
  collapsed, and any `¶` paragraph marks and `[` `]` bracket characters are
  removed. No words are added, removed or reworded.

## KJV — King James Version (`kjv`)

- Source: https://ebible.org/Scriptures/eng-kjv_vpl.zip (eBible.org id `eng-kjv`)
- Edition: King James Version, standardized text of 1769, source files dated 26 Sep 2026. Protestant canon only. The `¶` paragraph marks and the `[brackets]` around the translators' supplied words are removed; the words themselves are kept.
- Rights (https://ebible.org/eng-kjv/copyright.htm): Public Domain.

  > Letters patent issued by King James with no expiration date means that to print this translation in the United Kingdom or import printed copies into the UK, you need permission. Currently, the Cambridge University Press, the Oxford University Press, and Collins have the exclusive right to print this Bible translation in the UK. This royal decree has no effect outside of the UK, where this work is firmly in the Public Domain.

  Note: the KJV is in the public domain in the US. In the UK it is under Crown letters patent, which govern printing and importing printed copies.

- Source: https://ebible.org/Scriptures/engBBE_vpl.zip (eBible.org id `engBBE`)
- Edition: The Bible in Basic English, translated by Samuel Henry Hooke (Cambridge, 1965), source files dated 30 Aug 2018.
- Rights (https://ebible.org/engBBE/copyright.htm): Public Domain.

  > The Bible In Basic English was printed in 1965 by Cambridge Press in England. Published without any copyright notice and distributed in America, this work fell immediately and irretrievably into the Public Domain in the United States according to the UCC convention of that time. A call to Cambridge prior to placing this work in etext resulted in an admission of this fact.
